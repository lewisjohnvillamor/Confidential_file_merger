# Confidential File Merger

Fully offline, self-hosted PDF and image merger written in Rust.
Merge PDFs and images (PNG, JPEG, GIF, BMP, WebP, TIFF) into one PDF with a
drag-and-drop web GUI, without any third party ever seeing your documents.
